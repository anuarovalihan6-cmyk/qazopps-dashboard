# QazOpps Dashboard

QazOpps is a responsive dashboard concept designed to help students discover internships, hackathons, educational programs and other opportunities in Kazakhstan.

## Features

- Responsive dashboard layout
- Opportunity recommendations
- User statistics
- Profile progress tracking
- Modern UI design
- Mobile responsive interface

## Technologies

- HTML5
- CSS3
- Responsive Design

## Role

UI/UX Design and Frontend Prototype

The interface was designed as a web prototype for the QazOpps platform.
