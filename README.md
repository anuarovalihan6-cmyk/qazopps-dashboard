# QazOpps Dashboard

A modern responsive dashboard concept for discovering internships, hackathons, educational programs and career opportunities across Kazakhstan.

## 🚀 Live Demo

https://anuarovalihan6-cmyk.github.io/qazopps-dashboard/

## 📌 About the Project

QazOpps is a UI/UX and frontend prototype designed to make it easier for students and young professionals to discover relevant opportunities in Kazakhstan.

The dashboard provides a simple interface for browsing internships, educational programs, hackathons and other career opportunities.

## ✨ Features

- Responsive dashboard interface
- Opportunity search
- Category filtering
- Internship, education and hackathon categories
- Save / unsave opportunities
- Dynamic saved counter
- Interactive notifications
- Profile completion indicators
- Responsive layout for different screen sizes

## 🛠 Technologies

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- GitHub Pages
